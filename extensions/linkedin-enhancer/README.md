# LinkedIn Enhancer by José DA COSTA

Cross-browser extension that enhances LinkedIn with productivity tools.

- **Category**: productivity
- **Store status**: self-hosted (not published to public stores)
- **Browsers**: Chrome, Firefox, Edge, Opera, Safari (Brave uses the Chrome build)
- **Source code**: private
- **Latest release**: see the [latest release](https://github.com/josedacosta/josedacosta-extensions-releases/releases?q=linkedin-enhancer&expanded=true)

## Install

Download the build for your browser from the latest release, then follow the
repository [INSTALL.md](../../INSTALL.md).

## How releases reach this repo

The source lives in a private repository. On every `vX.Y.Z` tag, its release
workflow builds all browser targets and publishes them here as a release tagged
`linkedin-enhancer-vX.Y.Z`. The source archive is never published.
