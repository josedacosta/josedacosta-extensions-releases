# AI Chat Export by José DA COSTA

Browser extension to export AI chatbot conversations to clean Markdown, with all
links preserved.

- **Category**: productivity
- **Store status**: self-hosted (not published to public stores)
- **Browsers**: Chrome, Firefox, Edge, Brave, Opera
- **Source code**: private
- **Supported sites**: ChatGPT, Gemini, Claude, Perplexity, Grok, Mistral
- **Latest release**: see the [latest release](https://github.com/josedacosta/josedacosta-extensions-releases/releases?q=ai-chat-export&expanded=true)

## Install

Download the build for your browser from the latest release, then follow the
repository [INSTALL.md](../../INSTALL.md).

## How releases reach this repo

The source lives in a private repository. On every `vX.Y.Z` tag, its release
workflow builds all browser targets and publishes them here as a release tagged
`ai-chat-export-vX.Y.Z`. The source archive is never published.
